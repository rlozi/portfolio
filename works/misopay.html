PG 결제서비스 RESPONSIVE WEB DESIGN

  • UI/UX Design & Responsive Design
  • 작업기간 : 2 weeks

Overview

PG 결제 서비스는 결제와 관련된 다양한 기능과 정보를 제공하는 웹 기반 서비스로, 사용자가 결제 및 거래 정보를 편리하게 확인하고 관리할 수 있도록 UI/UX를
디자인 했습니다.

기획 단계에서 정의된 기능과 요구사항을 바탕으로 PC와 모바일 환경의 화면 구조를 구체화하고, 서비스 전반의 UI 디자인과 반응형 화면을 제작했습니다.

복잡한 결제 정보를 사용자가 쉽게 이해하고 필요한 기능을 빠르게 찾을 수 있도록
정보의 우선순위와 화면 구성을 정리했습니다.

Contribution
